## 1. مقدمة

### 1.1 الغرض من النظام
نظام "ناظم" هو نظام إدارة معاملات إلكتروني شامل مصمم لشركة نفط الوسط، يهدف إلى إلغاء التعامل الورقي بالكامل وأتمتة جميع المعاملات الرسمية والطلبات الإدارية وطلبات العمل.

### 1.2 الفلسفة الأساسية للنظام
النظام قائم على ثلاثة أركان أساسية يجب إعدادها بالتسلسل:

| الخطوة | الركن | الوصف |
|--------|-------|-------|
| 1 | **الهيكل التنظيمي** | بناء الهيكل الإداري الكامل للشركة بمستوياته الستة |
| 2 | **إدارة المستخدمين** | إنشاء حسابات الموظفين وربطهم بالأقسام وتحديد مناصبهم |
| 3 | **الصلاحيات** | منح كل مستخدم الصلاحيات المناسبة لموقعه الوظيفي |

بعد اكتمال هذه الأركان الثلاثة، يصبح النظام جاهزاً لتشغيل أنواع الطلبات الثلاثة:
- **المراسلات** (البريد الصادر والوارد)
- **الطلبات الخاصة** (إجازات وطلبات إدارية)
- **طلبات العمل** (خدمات صيانة وفنية وإدارية)

## 2. الهيكل التنظيمي (الركن الأول)

### 2.1 المستويات الإدارية الستة

| المستوى | المسمى | المسمى بالإنجليزية | الوصف |
|---------|--------|-------------------|-------|
| 1 | مدير عام | General Manager | أعلى سلطة في الشركة |
| 2 | معاون | Assistant GM | معاونو المدير العام (فني / إداري) |
| 3 | هيئة | Directorate | الإدارات العامة (مثل هيئة العمليات، هيئة المالية) |
| 4 | قسم | Section | الأقسام ضمن الهيئات |
| 5 | شعبة | Division | الشُعب ضمن الأقسام |
| 6 | وحدة | Unit | أصغر وحدة تنظيمية |

### 2.2 التصنيف المركزي
- الكيانات التي ترتبط مباشرة بالمدير العام أو المعاونين وليست ضمن هيئة معينة تُصنَّف كـ **"مركزي"**
- أمثلة: الهيئة القانونية، هيئة التفتيش، قسم الإعلام، قسم الأمن، قسم البيئة، قسم تكنولوجيا المعلومات

### 2.3 خصائص كل كيان تنظيمي

| الخاصية | الوصف | مطلوب |
|---------|-------|-------|
| الاسم (عربي) | الاسم الرسمي بالعربية | نعم |
| الاسم (إنجليزي) | الاسم بالإنجليزية | اختياري |
| المستوى | أحد المستويات الستة | نعم |
| مركزي | هل يرتبط مباشرة بالمدير العام/المعاون | نعم |
| الكيان الأب | الكيان الذي يتبع له في الهيكل | اختياري (الجذر فقط) |
| رمز القسم | رمز تعريفي مختصر (مثل: HR, FIN, OPS) | اختياري |
| صلاحية المراسلة الخارجية | هل يمكنه إرسال/استقبال مراسلات خارجية | نعم |
| الوصف | وصف اختصاصات الكيان | اختياري |

### 2.4 الهيكل الحالي لشركة نفط الوسط (مُنفَّذ)

```
مكتب المدير العام (GM)

│   │   ├── قسم العمليات النفطية (OPS-1)
│   │   │   └── شعبة الصيانة الميدانية (OPS-1-1)
│   │   │       └── وحدة المراقبة والتحكم (OPS-1-1-1)
│   │   └── قسم الإنتاج (OPS-2)
│   ├── هيئة الحفر (DRL)
│   │   └── قسم عمليات الحفر (DRL-1)
│   │       └── شعبة معدات الحفر (DRL-1-1)
│   ├── هيئة المشاريع (PRJ)
│   │   ├── قسم التصاميم الهندسية (PRJ-1)
│   │   └── قسم تنفيذ المشاريع (PRJ-2)

│       ├── قسم الجيولوجيا (GEO-1)
│       └── قسم المكامن (GEO-2)
├── معاون الشؤون الإدارية (AGM-A)
│   ├── هيئة الشؤون الإدارية والموارد البشرية (HR)
│   │   ├── قسم شؤون الموظفين (HR-1)
│   │   │   └── شعبة الخدمات الإدارية (HR-1-1)
│   │   └── قسم التدريب والتطوير (HR-2)
│   ├── هيئة الشؤون المالية (FIN)
│   │   ├── قسم الحسابات (FIN-1)

│   │   └── قسم الموازنة (FIN-2)
│   ├── هيئة العقود والمشتريات (CNT)
│   │   ├── قسم العقود (CNT-1)
│   │   └── قسم المشتريات (CNT-2)
│   ├── قسم تكنولوجيا المعلومات [مركزي] (IT)
│   └── قسم المخازن (WH)
├── الهيئة القانونية [مركزي] (LEG)
├── هيئة التفتيش والرقابة [مركزي] (INS)
├── هيئة التخطيط والمتابعة [مركزي] (PLN)
├── قسم الإعلام والعلاقات العامة [مركزي] (MED)
├── قسم الأمن والحماية [مركزي] (SEC)
└── قسم البيئة والسلامة [مركزي] (ENV)
```

## 5. المراسلات (النوع الأول من الطلبات)

### 5.1 أنواع المراسلات الأربعة

| النوع | المسمى | الوصف | مثال |
|-------|--------|-------|------|
| صادر داخلي | internal_outgoing | مراسلة من كيان داخلي إلى كيان داخلي آخر | تعميم من المدير العام لجميع الهيئات |
| صادر خارجي | external_outgoing | مراسلة من الشركة إلى جهة خارجية | رد على وزارة النفط |
| وارد داخلي | internal_incoming | مراسلة مستلمة من كيان داخلي | تقرير من هيئة العمليات |
| وارد خارجي | external_incoming | مراسلة مستلمة من جهة خارجية | كتاب من وزارة النفط |

### 5.2 مسار سير المراسلة (8 حالات)

```
مسودة (draft)
  ↓ [الموظف يرسل للمراجعة]
قيد المراجعة (under_review)
  ↓ [المسؤول المباشر يرفع للموافقة]
بانتظار الموافقة (pending_approval)
  ↓ [صاحب الصلاحية يوافق]
تمت الموافقة (approved)
  ↓ [الجهة المختصة تُصدر الرقم المرجعي]
صدر (issued) ← يُمنح رقم مرجعي تلقائي: [رمز القسم]/[التسلسل]/[السنة]
  ↓ [يُحال للتنفيذ]
قيد التنفيذ (in_progress)
  ↓ [يتم إنجاز المطلوب]
مكتمل (completed)
  ↓ [تُحفظ في الأرشيف]
مؤرشف (archived)
```

| القسم المستلم | الكيان المستلم (للمراسلات الداخلية) |

| المراسلة الأم | ربط الرد بالمراسلة الأصلية (تسلسل المراسلات) |

### 5.4 نظام الإسناد (التكليف)
- كل مراسلة يمكن إسنادها إلى كيان واحد أو أكثر
- يُحدَّد **كيان رئيسي** (Lead) مسؤول عن التنفيذ
- يُحدَّد **كيانات مساندة** (Supporting) للمشاركة
- نسخ إلى (CC): كيانات تُبلَّغ للعلم فقط

## 11. ملخص حالة التنفيذ الإجمالية

### ما تم إنجازه ✅
1. الهيكل التنظيمي بالمستويات الستة مع البيانات الحقيقية لشركة نفط الوسط
2. قاعدة بيانات شاملة تغطي جميع الكيانات والعلاقات
3. واجهات أساسية لجميع الصفحات (لوحة التحكم، المراسلات، الإجازات، الخدمات، الهيكل)
4. نماذج إنشاء للمراسلات والإجازات والخدمات والأقسام
5. نظام المصادقة عبر Replit Auth
6. سجل المراجعة للمراسلات
7. واجهة API كاملة مع التحقق من صحة البيانات

### ما يحتاج إلى تنفيذ ❌ (مرتب حسب الأولوية)
1. **صفحة إدارة المستخدمين** - إنشاء وتعديل وتعيين الأدوار والأقسام
2. **نظام الصلاحيات** - التحقق من الدور + تصفية البيانات حسب النطاق
3. **واجهة تفاصيل المراسلة** - عرض كامل مع الإسناد والردود وتغيير الحالة
4. **واجهات الموافقة/الرفض** - للإجازات والخدمات والمراسلات
5. **مسار الموافقة التسلسلي** - التوجيه التلقائي للمسؤول التالي
6. **نظام الإشعارات** - إبلاغ المستخدمين بالمعاملات الجديدة
7. **إرفاق الملفات** - رفع وتحميل المرفقات
8. **تعديل وحذف الأقسام والموظفين**
9. **التقارير والإحصائيات المتقدمة**
10. **الطباعة والتصدير**
